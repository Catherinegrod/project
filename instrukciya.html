Инструкция по добавлению стихотворений

Как правильно оформить текст стихотворения, что бы все работало

Для того, что бы стихотворение работало — средства художественной выразительности выделялись, нужно соблюдать несколько правил при добавлении.
  • Указывайте название с большой буквы, без кавычек
  • Указывайте у автора инициалы и фамилию, например И.И. Иванов
  • Указывайте жанр и эпоху с большой буквы
  • В самом тексте для выделения средств художественной выразительности используйте предложенные теги:
    до и после выделяемой части вставте
    • <metaphor>...</metaphor> — для метафор
    • <olitsetvorenie>...</olitsetvorenie> — для олицетворения
    • <epithet>...</epithet> — для эпитета
    • <sravnenie>...</sravnenie> — для сравнения
    • <metonimiya>...</metonimiya> — для метонимии
    • <giperbola>...</giperbola> — для гиперболы
    • <litota>...</litota> — для литоты
    • <alliteration>...</alliteration> — для аллитерация
    • <assonance>...</assonance> — для ассонанса
    • <anaphora>...</anaphora> — для анафоры
    • <epifora>...</epifora> — для эпифоры
    • <parcellation>...</parcellation> — для парцелляции
  • Для перехода на следущую строку в конце каждой строки указывайте <br>

    • Пример готового стихотворения:

    Умом Россию не понять,<br>
    <metaphor>Аршином общим не измерить</metaphor>:<br>
    У ней особенная стать —<br>
    В Россию можно только верить.
